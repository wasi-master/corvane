## v0.4.0 — 2026-09-30

### Added

- Diff highlighting now uses CodeMirror modes ported to Rust ✨
- `Cmd+Shift+P` opens the command palette (see <kbd>Cmd</kbd>)
- Emoji in commit messages: 👩‍💻 🧑🏽‍🚀 🇯🇵 render correctly
  - positions are UTF-16 units, so `😀` counts as two
  - *emphasis after emoji 😀* and **strong 🚀** and _under 🎉_
  - 😀*star after emoji*😀 and 🎉_underscore_🎉

### Fixed

1. Crash when a repository path contains `日本語`.
2. **Bold** at the start of an item.
3. `code` at the start of an item.
4. [Link](https://example.com/issues/42) at the start of an item.
